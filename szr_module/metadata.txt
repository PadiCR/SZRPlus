about=SZR+ (Susceptibility Zoning + Raster) is an independent fork of SZ-plugin 1.1.5 for data-driven susceptibility mapping of landslides and other natural hazards. It adds native raster processing and a redesigned didactic GUI whose lateral information panels explain each model and tool, its required inputs and when to use it. Weight of Evidence, Frequency Ratio, Logistic Regression, Decision Tree, Support Vector Machine and Random Forest are available in both vector and raster modes, with train-test and k-fold cross-validation, ROC and AUC validation, and susceptibility index classification. SZR+ continues the SZ-plugin 1.x codebase and does not follow the space-time modelling direction of upstream SZ-plugin 2.x. EXTERNAL DEPENDENCIES: this plugin requires the Python packages scikit-learn, geopandas, libpysal and seaborn, which are not shipped with QGIS. The plugin detects missing packages and asks for your confirmation before installing anything; you can also install them yourself beforehand, for example by running "python -m pip install scikit-learn geopandas libpysal seaborn" in the OSGeo4W Shell on Windows, or in the Python environment running QGIS on Linux and macOS. On Debian and Ubuntu the automatic installation also needs the python3-venv package, which those distributions ship separately from Python itself ("sudo apt install python3-venv"). Originally built upon SZ-plugin by Giacomo Titti (giacomotitti@gmail.com).

changelog=1.10.2 - Dependency installation fixes, mainly on Linux. Fixes: a failed virtual-environment creation or pip install no longer reports 'Packages successfully installed' and then fails to import scikit-learn - every command failure now surfaces with its reason and the installation stops; an environment left half-created by an earlier failed attempt is detected and recreated instead of being reused indefinitely; on Debian and Ubuntu, where the ensurepip module ships in a separate package, the installer explains that python3-venv is required and gives the exact apt command; the 'installed' flag is only stored once all four required modules really import, so a failed run no longer leaves the plugin convinced its dependencies are present; the Windows and Linux interpreter layouts are now selected explicitly instead of by catching an exception, which was hiding the real errors underneath; and an unused pkg_resources import was removed before its planned removal from setuptools breaks the installer. Interface: the dependency dialogs and the Log Messages panel tab now say SZR+ instead of SZ-plugin.
    1.10.1 - Vector Base fixes and Classify SI parity with the raster mode. Fixes: Weight of Evidence and Frequency Ratio no longer leak raw covariate values into the test Susceptibility Index (unseen classes now contribute a neutral 0), which previously inflated or corrupted every test score; the Vector Base backend no longer fails on a missing module or a wrong parameter key; and a stray local import that broke the Classify SI tools was removed. New: WoE and FR refuse to run on continuous covariates and explain how to classify them; Binomial vector mode writes a single Susceptibility Index GeoPackage covering every slope unit, with a split field marking Train/Test; Classify SI (vector) gains Closest Point (0,1), F1-Score, Threat Score (CSI) and Youden's J, and now produces a classified layer with named classes and the RdYlGn colour ramp, matching the raster tools; Youden's J added to the raster mode too; every threshold method gains a Class Break Method (equal interval or quantile) and writes a confusion-matrix and metrics CSV; new-field names are validated against the shapefile 10-character limit.
    1.10 - Redesigned GUI in a resizable window with the QGIS icon in its title bar, an in-panel message bar and theme-aware styling (light/dark); native extent and multi-field selectors; runs execute on the QGIS task manager and are cancellable; much faster start-up (dependencies are no longer re-checked via pip on every launch); pages are built on demand; result raster styles are stored as .qml sidecars so they survive reloading. Fixes: Vector Base runs failing with an undefined variable, Classify Vector by ROC/Weighted ROC failing on a bad parameter key, and Data Preparation failing when a non-temporary output file was chosen.
    1.9 - Minor information panel text edits and clarifications.
